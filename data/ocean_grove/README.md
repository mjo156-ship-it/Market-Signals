# Ocean Grove STR Opportunity Report

A **weekly** report of properties **for sale in Ocean Grove, NJ** (Neptune
Township, Monmouth County) with an assessment of their short-term-rental (STR)
potential — gross rental earnings, operating income, and operating income **net
of tax** after applying a **100% bonus-depreciation** benefit in the purchase
year (basis split **40% land / 60% building**). It flags properties that can
break even on an annual operating basis.

Generated by [`ocean_grove_str.py`](../../ocean_grove_str.py) and refreshed every
Monday by [`.github/workflows/ocean_grove_str.yml`](../../.github/workflows/ocean_grove_str.yml).

## Files (the data contract)

| File | Purpose |
| --- | --- |
| `latest.md` | Rendered weekly report (reads on GitHub). |
| `latest.json` | Full structured data — meta, assumptions, summary, per-listing waterfall. |
| `history/<week-of>.json` | Dated archive, one per weekly run (Monday of that week). |

## Data source (pluggable)

`fetch_listings()` resolves the for-sale set in priority order:

1. **`$OG_LISTINGS_JSON`** — path to a JSON file of real listings you drop in
   (same schema as `SAMPLE_LISTINGS`). Either a bare array or `{"listings": [...]}`.
2. **`$RENTCAST_API_KEY`** — live pull from RentCast (wired as a stub in
   `_fetch_rentcast`; enable by filling in the request + mapping).
3. **`SAMPLE_LISTINGS`** — a curated, clearly-labelled **representative** set used
   when no live source is configured, so the report runs out-of-the-box. These are
   illustrative, **not** live MLS rows. The report's `meta.data_source` says which
   source produced it.

The financial engine is identical regardless of source.

## The model

**STR revenue** is a seasonal buildup (Ocean Grove is an intensely seasonal shore
market — Sat-to-Sat weekly summer bookings, quiet winters): a peak weekly rate
(by bedroom count, or per-listing override) scaled across peak / shoulder /
off-season weeks and occupancies.

**Operating income (NOI)** = gross STR revenue − operating expenses (management,
platform fees, cleaning, supplies, capex reserve, property tax, insurance,
maintenance, utilities, condo fee, CMA ground lease, STR license). Excludes debt
service and depreciation.

**Net of tax** applies the **100% bonus depreciation** on the **60% building
basis** (land 40% is not depreciable) as a purchase-year deduction. STR losses
are assumed **non-passive** (avg stay ≤ 7 days + material participation — the
"STR loophole"), so the year-1 loss offsets ordinary income; the tax reduction is
treated as a cash benefit. Depreciation is non-cash, so it is added back to reach
after-tax **cash flow**.

Three break-even tests are reported per listing:

| Test | Meaning |
| --- | --- |
| `breaks_even_purchase_year` | Year-1 after-tax cash flow (financed) ≥ $0 — break-even **with** the bonus-depreciation shield. Nearly always true; the shield swamps the operating loss. |
| `breaks_even_sustained` | Stabilized (yr 2+, no depreciation) after-tax cash flow (financed) ≥ $0 — the strict **self-funds every year** test. |
| `breaks_even_operating_allcash` | Stabilized after-tax cash flow ≥ $0 **unlevered** — the asset covers operating costs net of tax without financing drag. |

Two discriminating metrics tie them together:

- **`break_even_down_pct`** — the equity fraction at which stabilized after-tax
  financed cash flow reaches $0 (lower = more attractive).
- **`horizon_years`** — how many years the one-time year-1 tax windfall keeps the
  cumulative after-tax position non-negative before stabilized operating losses
  draw it down (`null` = sustained).

## Assumptions (all overridable via env vars)

Every assumption is echoed into `latest.json → assumptions` so results are
reproducible. Key defaults: 40/60 land/building split, 100% bonus depreciation,
37% blended marginal tax, 20% down / 30-yr @ 7%, 20% management. Override any via
`OG_*` environment variables (see the `CONFIG` block in `ocean_grove_str.py`).

```bash
# examples
OG_MARGINAL_TAX_RATE=0.45 OG_DOWN_PAYMENT_PCT=0.35 python3 ocean_grove_str.py
OG_LISTINGS_JSON=my_listings.json python3 ocean_grove_str.py
```

## Ocean Grove specifics

- Most lots sit on a **99-year ground lease from the Ocean Grove Camp Meeting
  Association (CMA)** — you typically own the *building* on leased land. An annual
  ground-lease fee is included in operating costs. Because the land is not owned,
  a higher building allocation than 40/60 could arguably be justified (which would
  *increase* the year-1 depreciation shield).
- **Neptune Township has been tightening STR rules** (minimum-stay, bonding).
  Confirm current licensing before underwriting.

> **Not investment, tax, or legal advice.** A simplified underwriting model with
> estimated inputs. Depreciation recapture on sale, passive-activity limits,
> financing eligibility on leased land, and actual booking performance are not
> modeled. Verify every figure and consult a CPA/attorney before transacting.
